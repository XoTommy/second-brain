# DMO Obsidian Pack

Copy this `DMO` folder into your Obsidian vault.

Open `00_DMO_Home.md` first.

The smaller topic notes are the day-to-day source of truth.  
`99_DMO_Full_Archive_v2.2.md` is retained only as a complete historical/cross-chat archive.

## Update rule

- product/architecture → Main Synopsis
- completed work/tests → Progress So Far
- rug/scam work → Rug Defense
- caller/channel work → Source Network
- missed runner/promotion → Runner Improvements
- reverse engineering → GemBot Reverse Engineering
- hosting/relay → Runtime, Cloud & Publication
- live results → Evaluation & Track Record
- agreed next work → Plans & Priorities
- failures → Incidents & Lessons
- repo/branch/commit/path → Repos & Handoffs
- public/private membership → Social & Monetization
