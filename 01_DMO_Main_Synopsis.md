# DMO — Main Synopsis

## What DMO is

DMO = **Don't Miss Out**.

It is a crypto intelligence/call system built to discover meaningful opportunities **before they become obvious**, verify enough to act intelligently, explain risks and uncertainty, publish only justified calls, and track every result.

DMO is not a Telegram firehose, generic price scanner, blind caller copier, automatic trader, or guaranteed-profit service.

## Core loop

```text
SENSE → DISCOVER → IDENTIFY → PRIORITIZE → INVESTIGATE
→ VERIFY → CONTEXTUALIZE → COUNTER-EVIDENCE → ASSESS
→ NOTIFY → REVISIT → TRACK OUTCOME → LEARN
```

## Current operating thesis

The source-driven Beta is already finding real multi-x runners. The immediate goal is not another rebuild.

> **Preserve early-runner discovery while removing/warning on as much prospectively provable scam/rug capability as possible.**

Opportunity quality and safety are separate axes:

```text
Is this likely worth acting on?
+
Can somebody demonstrably destroy this market?
```

A coin can be a runner and still be rug-capable.

## V1 / V2 / V3

### V1 — Revenue Engine
Fast, selective, low-cost, source-driven intelligence that can make useful calls now.

### V2 — Intelligence Engine
Adaptive investigation, stronger wallet/actor reasoning, better source reliability, narrative/catalyst intelligence, next-play radar.

### V3 — Autonomous Intelligence System
Continuous multi-source discovery, autonomous hypotheses, investigation memory/knowledge graph, custom models, continuous learning.

## Evidence rules

Every important decision should preserve:

- chain + contract;
- source + first-seen time;
- point-in-time MC/liquidity;
- canonical market;
- verified vs claimed vs unknown evidence;
- risk evidence;
- decision reason;
- later outcome stored separately.

**Anti-lookahead is non-negotiable.**

## Current Rug Defense labels

- **PASS** — scoped checks completed; no supported catastrophic capability found.
- **CAREFUL** — real suspicious evidence, but below VETO proof.
- **UNKNOWN** — safety evidence could not be reliably acquired/validated.
- **VETO** — verified destructive control/mechanism plus applicable current capability.

Only VETO is intended eventually to block a valid DMO opportunity.

## Current product correction

DMO must not confuse **internal workflow state** with **market earliness**.

An `EARLY WATCH` after a token already expanded several multiples is not early to the user.
